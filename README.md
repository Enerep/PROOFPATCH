### ProofPatch — Don't Trust the Agent. Test the Result.

**Description:** ProofPatch is an open-source developer tool that independently tests AI-generated code to verify whether it actually works. Designed for AI coding tools like Claude Code, Codex, and Cursor, it automatically runs tests, detects bugs, checks real-world user scenarios, and generates transparent verification reports.

Starting with web applications, ProofPatch aims to make AI-assisted software development safer, more reliable, and trustworthy—helping developers ship code based on evidence, not just AI claims.
